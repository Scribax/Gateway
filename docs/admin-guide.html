Runbook de produccion

Configura el gateway sin exponer el panel administrativo.

Completa los pasos en orden. Los comandos se actualizan con los datos privados cargados en esta pestaña.

Arquitectura protegidaPortal publico en `/`, relay publico en `/v1/` y New API admin disponible solamente mediante tunel SSH.
00

Caja privada

Los valores viven en sessionStorage y se eliminan al cerrar la pestaña o pulsar limpiar.

Datos de accesoNo se envian ni se escriben dentro del HTML
La contrasena SSH no debe guardarse aqui. Usa un gestor de contrasenas y migra a clave SSH.
01

Acceso administrativo

El panel no debe abrirse en Nginx. Se accede desde Windows por un tunel cifrado.

02

Inicializacion

New API no trae credenciales predeterminadas. El primer administrador se crea una sola vez.

CuentaCompletar en la caja privada

Rol administrador y estado habilitado.

ContrasenaNo cargada

Unica, larga y almacenada en un gestor.

ModoOperacion / publico

Self-use desactivado para facturar clientes.

Sitio demoDesactivado

No habilitar funciones demostrativas en produccion.

No reutilices la contrasena de SSH como contrasena de New API. Tras crear el administrador, `/setup` debe dejar de aparecer.

06

Prueba de fuego

Comprueba respuesta, tokens y descuento de saldo con una subclave; nunca con la clave madre.

PowerShell local
Set-Location "C:\ruta\Gateway"
python .\check_usage.py
python .\test_relay.py --model gpt-5.4-mini --prompt "Responde solamente OK"
python .\check_usage.py
La prueba se considera aprobada cuando respuesta, registro de consumo y deduccion coinciden en la misma operacion.
